# Listening Strategies

30 分钟 + 10 分钟誊写,4 个 Section,40 题。

> ⚠️ **限制**: 本 skill 无法播放音频。听力练习采用**脚本模式**: 展示听力原文 + 题目,让用户做精听整理。**配合 materials 模块的 YouTube 视频做真听力训练**。

---

## 4 个 Section 概览

| Section | 场景 | 内容 | 题型 |
|---|---|---|---|
| 1 | 日常对话 | 租房 / 咨询 / 报名 | Form / Note completion |
| 2 | 独白 | 旅游介绍 / 设施介绍 | Map / Multiple choice / Matching |
| 3 | 学术对话 | 学生讨论 / 学生与导师 | MCQ / Matching / Completion |
| 4 | 学术独白 | 讲座 | Note / Summary completion |

难度递增。7+ 目标 = 错 5 题以内。

---

## Section 1: 日常对话

### 高频场景与必备词汇

- **租房**: rent, deposit, lease, landlord, tenant, furnished, utility bills, parking
- **健身房**: membership, off-peak, induction, locker, instructor, fee, annual
- **图书馆**: borrow / return, due date, fine, renewal, reference section
- **银行**: account, balance, transfer, withdraw, deposit, ATM, branch
- **保险**: claim, premium, coverage, policy, excess, deductible
- **酒店**: reservation, check-in/out, suite, en-suite, sea view, breakfast included
- **报名**: registration, application form, fee, identification, beginner/intermediate/advanced

### 易错点

- **人名/地名**: 一定会拼写 (有时一字母 / 一字母念出)
- **电话号码**: 区号 + 长串,注意 oh = 0, double = 两个同号
- **日期**: 美式 (Month/Day) vs 英式 (Day/Month) 注意
- **价格**: pound / dollar / cent / pence 单位
- **拼写**: 双辅音 (e.g., accommodation), 沉默字母

## Section 2: 独白介绍

### 高频场景

- **新设施介绍** (sports centre, museum, library, park)
- **旅游介绍** (city tour, theme park, historical site)
- **公司介绍** (training course, internship program)
- **新员工/学生指南** (campus tour, dorm rules)

### 题型攻略

#### Map (地图题)
- **方向词**: north / south / east / west; opposite / adjacent / next to / across from / behind / in front of / between
- **路径**: go straight / turn left / on your right / at the end of...
- **建筑特征**: round / square / two-storey / glass-fronted

#### Matching
- 几个选项配几道题,先看选项找差异 → 听音区分

#### MCQ
- 三个选项,陷阱在**先错后对** (说一个又改一个)

## Section 3: 学术对话

### 场景

- 学生 + 导师 (论文进度讨论)
- 两个学生 (小组项目讨论)
- 三个学生 (合作分工)

### 关键词识别

| 信号 | 含义 |
|---|---|
| Actually... | 转折,前面错后面对 |
| But / However | 转折 |
| Let me think... | 思考,后面是答案 |
| So you mean... | 总结对方意思 |
| That's right / Exactly | 确认 |
| I don't think so / Actually no | 否定 |

### 易错点

- **观点归属**: 听清是哪个学生说的
- **修正**: 先说一个答案再改 → 选改后的
- **总结**: 长讨论后,常有一句"so we agree..."给最终答案

---

## Section 4: 学术讲座 (独白)

### 高频学科

- 历史 / 考古 / 地理 / 生物 / 心理 / 教育 / 商业 / 环境

### 结构

```
Introduction (背景)
Body 1: 第一个研究 / 第一个方面 (定义 + 例子)
Body 2: 第二个方面
Body 3: 第三个方面
Conclusion: 总结 + 展望
```

### 题型: Note Completion

- 通常按演讲顺序
- **字数限制严格** (NO MORE THAN TWO WORDS): 超字数 = 错
- 拼写错 = 错 (即使语音正确)
- 单复数错 = 错

### 听力路标

| 路标词 | 信号 |
|---|---|
| First / Initially / To begin with | 列举开始 |
| Second / Next / Then | 列举继续 |
| Finally / Last(ly) | 列举结束 |
| Moreover / In addition | 同向补充 |
| However / On the other hand | 转折 |
| For example / Such as | 例子 |
| In conclusion / To summarise | 总结 |

## 通用解题流程

```
1. 拿到卷子 → 划重点 + 预测答案类型 (名词? 数字? 形容词?)
2. 听音 → 听到关键词前后 → 立即写答案
3. 题号顺序基本与音频顺序一致 (Matching/Map 除外)
4. 错过一题 → 立即放弃, 跳到下一题, 不要纠结
5. 最后 10 分钟誊写到答题卡 (字迹工整, 大小写规范)
```

---

## 答案规范 (誊写时常被忽略导致丢分)

- **大小写**: 句首/专有名词大写; 其他通常小写都接受
- **缩写**: $5 ≠ five dollars (按题目所要)
- **拼写**: 字典拼写 (不要美式英式混用)
- **单复数**: 注意题干提示 (How many? → 数字)
- **字数**: NO MORE THAN THREE WORDS 真的是 ≤3 个词,a/the 算

## 脚本模式练习 (本 skill 内)

每次 `practice mock listening` 流程:

1. skill 展示一段听力**原文** + 题目
2. 用户**先做题** (建议遮住原文,只看题目)
3. 完成后对答 + 解析
4. 总结**场景词** + **路标词** + **同义替换**
5. 错题入 errors.json

**用户应配合真音频做精听训练**:
- 找剑桥真题音频 (用户自有) 或 BBC 6 Minute English 之类视频 (用 materials 模块)
- 第一遍盲听 → 第二遍跟脚本听 → 第三遍只听核心句

---

## 弱听音点 (中国学生易错)

- **数字**: thirteen vs thirty, fifteen vs fifty (词尾 -teen 重读, -ty 弱读)
- **冠词**: a / the 不重读, 易漏听
- **连读**: pick it up → pi-ki-tup
- **失爆**: sit down → si(t) down
- **辅音群**: scripts / texts / asked (注意词尾)
- **同音异义**: their / there / they're

---

## 出题原则 (skill 模拟时)

- 每个 section 8-10 题
- 题型与真考一致
- 给原文 (用户做完才能看)
- 给答案 + 详细解析 (定位句 + 同义替换)
- 错题入库
