# Reading Strategies

学术类 60 分钟,3 篇文章,40 题。

---

## 11 类题型 + 应对

### 1. Multiple Choice (单选)
- **难度**: ★★★
- **顺序**: 通常按文章顺序
- **策略**: 先看题干画关键词 → 定位段落 → 逐选项对照
- **陷阱**: 选项可能两个看似对,选**信息更全面**的;绝对化词 (always/never) 多为干扰

### 2. True / False / Not Given (T/F/NG)
- **难度**: ★★★★ (最易错)
- **顺序**: 按文章顺序
- **判断逻辑**:
  - **True**: 文章直接说 OR 同义改写
  - **False**: 文章直接相反 OR 矛盾
  - **NG**: 文章没提 OR 提了但没说对错
- **关键**: 不要用常识判断,只看文章。"作者认为"≠"事实"

### 3. Yes / No / Not Given (Y/N/NG)
- 同 T/F/NG,但针对**作者观点**而非事实
- 关键词: argue / believe / claim / suggest

### 4. Matching Headings (段落配标题)
- **难度**: ★★★★
- **顺序**: 不按文章顺序
- **策略**: 先看 headings 找关键词 → 读每段 topic sentence + 末句 → 匹配
- **陷阱**: 干扰 heading 通常只对应段落中的次要信息

### 5. Matching Information (信息配段落)
- **难度**: ★★★
- **顺序**: 不按
- **策略**: 题目找关键词 → 扫描文章定位 → 不要选只出现关键词的段,要选**完整对应信息**的段
- 一段可能匹配多题,也可能不匹配

### 6. Matching Features (配特征)
- 如把研究配研究者,把观点配人
- **策略**: 先在文章中标注每个人/物的位置 → 题目再找对应

### 7. Matching Sentence Endings (句子配尾)
- **顺序**: 按文章顺序
- **策略**: 题干句关键词定位 → 看选项哪个语法 + 逻辑都通
- **陷阱**: 选项数 > 题目数,有干扰

### 8. Sentence Completion (句子完成)
- 用文章原词填空,字数限制
- **策略**: 看题目找定位词 → 找到原句 → 抠词
- **陷阱**: 字数超过限制 = 错;原词,不要改写

### 9. Summary / Note / Table / Flowchart Completion
- 类似 sentence completion 但有文本框架
- **策略**: 先看框架理解结构 → 找定位词 → 抠词
- **陷阱**: 可能来自文章某一段,先定位段再细读

### 10. Diagram Label Completion
- 看图填标签
- **策略**: 图 + 文章对照,通常文章某段描述图

### 11. Short-Answer Questions
- 用文章信息回答开放问题
- **策略**: 题目关键词 → 找原文 → 直接抠答案

## 通用解题流程

```
1. 跳过文章, 直接看题目 → 圈关键词 (人名/地名/数字/专有名词最易定位)
2. 文章扫读一遍 (1-2 分钟) → 知道每段大意 (画段落标签)
3. 按题目顺序做 (T/F/NG, MCQ, Completion 等顺序题)
4. 不按顺序的题 (Matching Headings, Information) 留最后
5. 不确定的题先标记 + 跳过, 最后回来
6. 涂答题卡 (最后 5 分钟)
```

| Passage 1 | 易 | 17 分钟 |

| Passage 3 | 难 | 20 分钟 |
| 涂卡/检查 | - | 3 分钟 |

7+ 目标 = 错 8 题以内 (即对 ≥ 33)。

## 长难句拆解

### 三步法

1. **找主干**: 主语 + 谓语 + 宾语 (跳过修饰)
2. **拆从句**: 标记 which / that / who / where / when / because / although / if 等连接词
3. **理逻辑**: 让步 / 因果 / 对比 / 时序

### 例

> Although researchers had long suspected that the practice, which originated in ancient civilizations and was subsequently refined over centuries, played a critical role in shaping modern medicine, definitive evidence remained elusive until recent advances in archaeological methods allowed for more rigorous analysis.

**拆解**:
- 主干: definitive evidence remained elusive
- Although 让步: researchers had long suspected that... played a critical role
- which 定语: the practice (originated... and refined...)
- until 时间: recent advances... allowed for analysis

**翻译**: 虽然研究者长期怀疑这一起源于古代文明、历经几世纪精炼的实践对现代医学起了关键作用,但确凿证据一直难寻,直到近期考古方法进步才能更严格分析。

## 同义替换 (定位关键)

文章很少与题目用同样的词。例:

| 题目词 | 文章常见同义 |
|---|---|
| children | youngsters / kids / minors / the young |
| help | aid / assist / facilitate / support |
| important | crucial / vital / pivotal / essential |
| difficult | challenging / demanding / arduous |
| cause | trigger / lead to / result in / give rise to |
| many | numerous / a multitude of / a wealth of |

---

## 常见陷阱

1. **绝对化干扰**: 文章说 some / many → 选项写 all 通常错
2. **比较级陷阱**: 文章说 X 高,选项问 X 是不是最高 → NG
3. **时间陷阱**: 文章说 1990s,题目问 1980s
4. **因果倒置**: 文章 A → B,题目说 B → A
5. **作者立场误读**: critics argue X 不代表作者支持 X

---

## Skill 出题原则

模拟阅读时:
- 篇幅 700-900 词
- 题型混合 (12-13 题: T/F/NG 4 题 + MCQ 3 题 + Headings 3 题 + Completion 3 题)
- 题号顺序符合文章顺序 (除 Matching 类)
- 提供答案 + 详细解析 + 同义替换对照表
