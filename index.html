配置 GitHub Personal Access Token (PAT) 后, 你在"计划"tab 选的明日内容会自动写回仓库, 早上 6 点 cron agent 读取生成。
如何获取 PAT:
1. 浏览器开 github.com/settings/personal-access-tokens/new
2. Token name: ielts-coach · Expiration: 90 天
3. Repository access: Only select repositories → ielts-coach
4. Permissions → Repository permissions → Contents: Read and write
5. Generate token, 复制 github_pat_xxx, 粘贴到上方框, 测试 → 保存
